CUSTECH Course Registration System

A full-stack course registration portal built for Confluence University of Science and Technology (CUSTECH). 

(https://custech-course-registration.vercel.app/)

 Tech Stack
Frontend: React, Vite, TailwindCSS 
Backend:  Python, FastAPI, SQLAlchemy 
Database: MySQL, TiDB Cloud

Key Features
Student Portal: Secure signup/login using matriculation numbers, course selection (1st & 2nd semester), carryover course search, and downloadable PDF course forms/receipts.
Admin Dashboard: View registered students, filter by department/level, delete registrations, and send direct warning messages to students.
Smart Parsing:  Automatically determines a student's department and academic level based on their matric number (e.g., `23L1CS0363`).
